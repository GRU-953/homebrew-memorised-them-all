# homebrew-memorised-them-all

Homebrew tap for **[Memorised them All](https://github.com/GRU-953/memorised-them-all)** by [GRU-953](https://github.com/GRU-953).

```bash
brew install GRU-953/memorised-them-all/mta
```

On first run, `mta` sets up a self-managed local virtualenv and installs its
dependencies (including the latest MarkItDown). For full features, install Ollama
and pull the models:

```bash
ollama pull qwen2.5:7b nomic-embed-text moondream
```
